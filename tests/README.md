# Проверки серверного назначения слотов

```bash
python3 tools/test_income_slots.py
```

Требуется системная `liblua5.4`. Runner через ctypes исполняет **точный исходник IncomeSlotService.lua** без преобразования кода; этот сервис использует синтаксис, совместимый и с Lua 5.4, и с Luau. PlayerDataStore подменяется контролируемой границей, серверное время задаётся тестом. Реальные профили не читаются и не изменяются.

22 проверки: установка, повтор без сброса таймера, устаревшая ревизия, двойное размещение, чужой предмет, заблокированный слот, другая активность, замена до/после часа, защита последнего источника, сохранение cooldown после снятия, занятая/закрытая сессия, PendingSpin, отказ сохранения, потерянный ответ после выполненной записи, закрытие во время сохранения, повреждённые связи и отсутствие начисления денег.

Это **не интеграционный тест Roblox**: сеть, настоящие DataStore, жизненный цикл Studio и обработчики RemoteEvent ещё требуют пользовательской проверки.
