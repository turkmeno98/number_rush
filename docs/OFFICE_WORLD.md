# Окружение — шаг 37

Пользователь указал, что UI работает, но физического офиса нет. В исходной сцене были только Baseplate/SpawnLocation. Добавлен воспроизводимый NumberRushOffice: шесть кабинетов с открытыми входами по сторонам общего коридора, столы, CRT-ПК, клавиатуры, кресла, SIM-боксы, по пять телефонов, окна и освещение. Размер основы 76×92 studs. Внешняя территория пока Baseplate, полноценного города нет.

OfficeScene (ModuleScript ServerScriptService) создаёт сцену только если NumberRushOffice отсутствует. В основной Studio геометрия создана в Edit и сохранена в place; в восстановленном XML из репозитория она появляется при запуске OfficeService. Экономика и DataStore не меняются. Копирование исходников не заменяет экспорт пользовательской геометрии.

OfficeService (Script ServerScriptService) назначает первый свободный кабинет, освобождает его после выхода, переносит персонажа в кабинет при появлении. Назначение действует на текущем сервере, это не сохраняемая собственность. Табличка показывает DisplayName, телефоны — доходные номера из серверного IncomeSlots. Изменения назначения обновляют дисплеи.

Клавиши: E — ПК/терминал, F — SIM-бокс/номера, G — телефоны/доходные слоты. Клиент открывает своё приложение только у предмета своего кабинета. У посетителя нет доступа к чужому профилю через эти действия; существующие серверные операции по-прежнему работают только с сессией отправителя. Номера на телефонах открыто видны посетителям. Общие кнопки слева остаются доступны. При входе UI свёрнут, чтобы офис был виден.

Первая генерация ProceduralModel дала только пять миниатюрных рабочих мест и не принята в качестве игровой сцены. Вместо неё используется OfficeScene с точной планировкой; внешних моделей/ассетов не требуется.

Структурно проверены 6 кабинетов, 6 ПК, 6 SIM-боксов, 30 телефонов, 42 подсказки взаимодействия. В Play MCP подтверждены назначение кабинета №1, перенос, владелец и отображение настоящего доходного номера на телефоне. Многоклиентские назначение/освобождение ещё требуют проверки; пользовательская оценка окружения впереди. Полноценный релиз по одному только UI ранее был оценён преждевременно.

Финал: E/F/G проверены реальными клавишами MCP, все три приложения открылись. tests/office_assignment.lua проверил точный серверный скрипт на клоне геометрии и fake Players: 6 уникальных кабинетов, освобождение, выдача освободившегося кабинета новому игроку и повторный сигнал входа без второго назначения. Это не 6 настоящих клиентов. Сохранена версия Studio 48, без публикации. Черновик генератора удалён из сборки, рабочая геометрия остаётся в Workspace.NumberRushOffice.
