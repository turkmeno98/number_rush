# Ограничения контрольной точки

Это снимок работающего по штатному сценарию прототипа, не релиз и не завершённый аудит.

1. **Оригинальный place-файл не получен.** Исходники восстановлены из чата. Сгенерированная геометрия — базовая, пользовательские изменения вне чата могут отсутствовать.
2. **Нет восстановления экономического цикла после расходования стартовых денег.** Доход и продажа пока не подключены. Обработчики SlotRequest/SlotResult и IncomeSlotService подготовлены, UI установки и начисление ещё отсутствуют. Длительный тест без следующего этапа может исчерпать баланс.
3. **IncomePerHour — метаданные.** Число слотов в профиле и описания дохода не означают начисление.
4. **UI последней карточки не восстанавливается из коллекции после входа.** Предметы могут быть сохранены, хотя окно снова показывает заглушку. Проверка через NumberInventory пользователем пройдена. Отдельный просмотр CollectionUI установлен, пользователь подтвердил работу.
5. **Отказные сценарии PendingSpin не проверены в Studio.** Требуются обрывы между сохранением удержания, Reserve, Confirm и финальным сохранением, повторные запросы и гонка серверов.
6. **Нет фонового согласования заброшенных резервов.** Пока ожидается восстановление при следующем входе владельца. Для масштаба понадобится безопасный reconciler, который не освобождает уже оплаченный/выданный номер.
7. **Исчерпание категории реализовано частично.** Сейчас 8 занятых кандидатов → отмена и возврат. Проектные пересчёт видимых шансов до покупки и активация резервных кодов ещё не написаны.
8. **Сессионные таймауты/закрытие не заменяют тестов.** Save(Closed) возвращает true как no-op; вызывающие сервисы обязаны проверять состояние. Проверить задержки >20–30 сек и потерю ответа на уже выполненную запись. Не обещать абсолютную сохранность на основании одного штатного теста.
9. **Валидация профиля начальная.** Проверяются базовые поля, но глубокая валидация Inventory/PendingSpin, миграции схем и восстановление повреждений ещё нужны перед релизом.
10. **Операции продажи/передачи Owned отсутствуют.** Registry.Cancel предназначен только для Reserved; нельзя использовать его как готовую продажу.
11. **Защита торгового переноса стартового капитала из v0.2 пока план.** Торговли ещё нет; при её добавлении внедрить сроки/прогресс и защиту премий.
12. **Политики платной случайности не реализованы.** VIP и Robux-продукты не подключены. Перед их добавлением — PolicyService, раскрытие конечных вероятностей и правил блатного отбора.
13. **Региональные связи кодов игровые.** Не утверждать соответствие реальным российским выделениям диапазонов.
14. **Размер GUI фиксирован 620×540.** Пользователь отклонил автоматическую коррекцию по обрезанному скриншоту. Мобильная адаптация позже.
15. **Внешние настройки не в исходниках.** Приватность, API Services, Max Players, Game Pass IDs и привязка к experience не восстанавливаются одной записью файлов.

Эти ограничения сохранены явно, а не исправлены скрытым изменением рабочего кода при резервном копировании.

16. **Назначение слотов — новая серверная часть шага 29.** 22 проверки точного исходника с подменённым хранилищем пройдены; запуск новой версии GameServer в Studio ещё не подтверждён. Профиль валидируется по его серверному Inventory; установки не меняют владельца в реестре. При добавлении торговли сохранять согласованность профиля и реестра.
