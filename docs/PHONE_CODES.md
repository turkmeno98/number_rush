# Откуда взяты коды операторов и регионов

Проверено 15.11.2026. Основной государственный адрес выгрузки в этой среде не открылся. Копия DEF на static.mts.ru доступна, но её Last-Modified — 27.02.2019; она не использована.

Рабочий источник: открытый проект [phoneoperator](https://github.com/MrProLopstar/phoneoperator), снимок данных от **26.10.2026**, закреплённый commit `7687c22cfc3b5243c15ee107a00b1af5b0d4ebe5`. Проект описывает извлечение из официального DEF-реестра и предоставляет MIT-лицензию. Это датированный снимок, не утверждение о полном соответствии изменениям после его даты и не поиск текущего оператора перенесённого номера.

- [Зафиксированные исходные данные](https://github.com/MrProLopstar/phoneoperator/blob/7687c22cfc3b5243c15ee107a00b1af5b0d4ebe5/src/data/mobile.ts).
- [Парсер источника и формат реестра](https://github.com/MrProLopstar/phoneoperator/blob/7687c22cfc3b5243c15ee107a00b1af5b0d4ebe5/scripts/fetch-data.ts).
- [Официальный адрес DEF-выгрузки](https://opendata.digital.gov.ru/downloads/DEF-9xx.csv).

Сырой снимок и лицензия сохранены в analysis/phone_catalog_sources, метаданные/хеш — catalog_manifest.json. tools/build_region_catalog.py не исполняет чужой TypeScript: читает JSON-литералы, декодирует данные и извлекает множества трёхзначных кодов. Seven-digit интервалы в игру не переносятся.

Операторы отбираются по ИНН, чтобы разные варианты названия юридического лица не терялись:

| Игра | Реальный источник | ИНН |
|---|---|---|
| БиЛайнк | ВымпелКом / Билайн | 7713076301 |
| Мобител | МТС | 7740000076 |
| МегаЛинк | МегаФон | 7812014560 |
| ТелеНова | Т2 Мобайл | 7743895280 |

В извлечении прочитано 4995 объединённых диапазонов этих четырёх юридических лиц. В каждом из 97 игровых пунктов есть коды из снимка; код может встречаться у нескольких операторов и регионов. Компоновки Москва+МО / СПб+ЛО разделяются на пункты с общим пулом. Миллионники дополнительно показываются как игровые города из регионального пула. Глобальный ключ владения по-прежнему полный номер, а не оператор/регион.

Список шестнадцати миллионников зафиксирован по перечню на начало 2025 года из [материалов ФИПИ](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/MR_geografia_ege_2025.pdf); это явная игровая конфигурация цен, не постоянно обновляемый демографический сервис.

Реестр выделений не описывает перенос конкретного номера между операторами. Реальные абоненты в игре не разыскиваются, звонки не выполняются; семь цифр — случайные игровые комбинации.

При обновлении снимка: сохранить новую дату/commit/лицензию, проверить метаданные, выполнить build_region_catalog.py, затем build_place.py и verify_snapshot.py. Исчезнувшие коды не освобождают чужие игровые номера автоматически.
