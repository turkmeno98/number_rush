# Согласованные правила интерфейса — шаг 33

Поправка шага 34: приложения открываются из постоянного меню слева поверх мира, инвентарь бустов только на нижней панели. Выдача — оператор+регион без выбора кода/гарантий (BALANCE_V03.md). Паспорт удалён; вместо него SIM-карточки с фирменными цветами, рамкой редкости, оценкой, доходом и кнопкой назначения. Новости редактируются в NewsConfig. Остальные решения ниже сохраняются, если не противоречат этой поправке.

15.11.2026. Решения пользователя по референсам; не возвращать прежний вариант общего инвентаря.

- Полноценный рабочий стол в стиле Windows XP: обои, цветные иконки, ярлыки, меню «Пуск», окна с перетаскиванием, сворачиванием и разворачиванием.
- Нижняя компактная панель эквивалентна терминалу: одна операция, одна последовательность запроса, один платёж. Анимация и результат синхронны. Можно запускать с последним выбранным оператором/кодом и разворачивать рабочий стол в процессе.
- «Список номеров» отдельно. «Инвентарь бустов» содержит только усиления; активация должна быть ручной после подключения выдачи и расходования бустов.
- Профиль публичный: точный текущий баланс, стоимость номеров, число номеров/попыток, лучший номер и установленные доходные номера. Лучший выбирается автоматически по SalePrice; равенство разрешается полным номером. Через список абонентов можно открыть профиль подключённого игрока.
- Состояние SIM-карты — только оформление, без новых денежных коэффициентов. Текущие формулы цены и дохода сохраняются.
- Почта: новости и системные награды; пересылки рублей/предметов нет. Новости отображаются; начисление наград ещё не подключено.
- Настройки: музыка, звуки, промокоды, предложения разработчику; приглашения — вместе с обменами. Ползунки управляют клиентскими SoundGroup NumberRushMusic / NumberRushEffects до выхода. Аудиотреки пока отсутствуют; промокоды и отправка предложений пока будущие функции.
- Доходные слоты: часовой cooldown отменён. Последний источник дохода по-прежнему нельзя снять.
- «Закрепить лучшее» оптимизирует все доступные слоты: доход/час по убыванию, затем SalePrice по убыванию, затем IssuanceId для стабильности. Подходят только Inventory/IncomeSlot. Прежние предметы возвращаются в список, лучший текущий набор не вызывает новую запись. Все изменения входят в одно сохранение профиля; остаток онлайн-дохода рассчитывается прежним механизмом.

Рынок, крафт, задания, магазин, VIP, пакетные выдачи и автопродажа остаются будущими системами. Не показывать вымышленные предметы, лоты, достижения и награды.
