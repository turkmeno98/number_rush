# Архив расчётов

Эти Python-скрипты и результаты сохранены как наработки проекта. `number_rush_balance` — исходная экономика с выявленными перекосами; `number_rush_rebalance` — пересчитанная v0.2. Runtime игры не импортирует эти файлы.

Зависимость вычислений: Python 3 и NumPy. Генераторы отчётов создают файлы только в своих каталогах, они отражают исторический черновик и не заменяют текущий `docs/BALANCE_V02.md` с финальными редакторскими уточнениями.

```bash
python3 analysis/number_rush_rebalance/calculate_v2.py
python3 analysis/number_rush_rebalance/check_rules.py
```

Не все утверждённые механики реализованы в коде. Результаты симуляций не означают выполненных тестов отказоустойчивости Roblox.
