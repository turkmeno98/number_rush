# NUMBER RUSH

Roblox-режим о коллекционировании российских телефонных номеров. Ретроофис связи, интерфейс в духе Windows XP, вымышленные операторы **БиЛайнк / Мобител / МегаЛинк / ТелеНова**.

**Контрольная точка: 15 ноября 2026, шаг 34. Выдача по оператору и региону без выбора кода и платных гарантий редкости. Общие шансы, цены 5000/7500/10000 ₽, 97 игровых пунктов из датированного справочника. Постоянное меню слева, брендированные SIM-карточки без паспорта, инвентарь бустов только внизу. Онлайн-доход работает, будущие системы не выдают фиктивных наград.**

## Продолжить работу

1. Прочитать [AGENTS.md](AGENTS.md).
2. Прочитать [точку продолжения](docs/HANDOFF.md), [состояние функций](docs/PROJECT_STATE.md), [выдачу v0.3](docs/BALANCE_V03.md) и остальные правила v0.2 с поправками.
3. Продолжить по актуальному HANDOFF: пользовательская проверка нового интерфейса; затем офлайн-доход и продажа.

## Что уже работает

- Четыре оператора и 97 пунктов выбора: обычные регионы, города-миллионники, Москва/Санкт-Петербург. Код выбирает сервер, шансы общие. Снимок справочника — 26.10.2026, не живая проверка перенесённых номеров.
- Распознавание шести категорий рисунков, генерация и оценка номера.
- Стартовые 100 000 ₽ только новому профилю, загрузка/сохранение баланса.
- Сессионная блокировка профиля, автосохранение, сохранение при выходе.
- Серверная обработка прокрутки, резервирование номера в общем реестре.
- Журнал незавершённой выдачи и предусмотренное восстановление при входе.
- XP-терминал: баланс, выбор кода, анимация, результат и количество предметов.

Не все предусмотренные защиты проверены отказами. Реализованный штатный сценарий и проектные гарантии разделены в [проверках](docs/TESTING.md).

**IncomeSlotUI и серверный онлайн-доход установлены в Studio.** Начисление идёт автоматически только за время текущей сессии, по ставкам установленных номеров. Офлайн-выплаты, продажа системе, рынок и VIP пока отсутствуют.

## Происхождение резервной копии

Исходники первоначально восстановлены из переписки. Теперь Studio подключена через MCP; шаги 30–31 внесены в открытый NUMBER RUSH [TEST]. Сборка в `places/` всё ещё не является полным экспортом оригинальной геометрии.

Собранный `.rbxlx` содержит рабочее дерево скриптов, четыре RemoteEvent, интерфейс слотов, онлайн-доход, простую площадку и точку появления. Геометрия исходной пользовательской сцены и её точные свойства не получены. Для полного оригинального снимка нужен экспорт `NUMBER_RUSH.rbxl` или `.rbxlx`; инструкция в [STUDIO_SETUP.md](docs/STUDIO_SETUP.md).

Данные Roblox DataStore, игровые балансы пользователей и настройки доступа к API в Git не экспортированы. Имена хранилищ и форматы сохранены в [DATA_AND_PROTOCOL.md](docs/DATA_AND_PROTOCOL.md). Не переименовывать их для обычных изменений кода.

## Восстановить

См. [пошаговую инструкцию Studio](docs/STUDIO_SETUP.md). Можно открыть готовый `.rbxlx` либо перенести скрипты вручную. Rojo не обязателен.

```bash
python3 tools/build_place.py
python3 tools/verify_snapshot.py
```

Эти команды проверяют файловый снимок. Для реальной проверки Luau, API, конкурентной выдачи и сохранений необходим Roblox Studio.
