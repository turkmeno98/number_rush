# NUMBER RUSH

Roblox-режим о коллекционировании российских телефонных номеров. Ретроофис связи, интерфейс в духе Windows XP, вымышленные операторы **БиЛайнк / Мобител / МегаЛинк / ТелеНова**.

**Контрольная точка: 15 ноября 2026, после шага 27. Пользователь подтвердил работу просмотра коллекции. Для шага 28 подготовлены события доходных слотов, обработчиков и начисления пока нет.**

## Продолжить работу

1. Прочитать [AGENTS.md](AGENTS.md).
2. Прочитать [точку продолжения](docs/HANDOFF.md), [состояние функций](docs/PROJECT_STATE.md) и [актуальный баланс v0.2](docs/BALANCE_V02.md).
3. Продолжить со **шага 26: проверить коллекцию после перезахода**, затем сделать просмотр коллекции и доходные слоты.

## Что уже работает

- Выбор четырёх операторов и 12 кодов, цены 5 000 / 15 000 / 50 000 ₽.
- Распознавание шести категорий рисунков, генерация и оценка номера.
- Стартовые 100 000 ₽ только новому профилю, загрузка/сохранение баланса.
- Сессионная блокировка профиля, автосохранение, сохранение при выходе.
- Серверная обработка прокрутки, резервирование номера в общем реестре.
- Журнал незавершённой выдачи и предусмотренное восстановление при входе.
- XP-терминал: баланс, выбор кода, анимация, результат и количество предметов.

Не все предусмотренные защиты проверены отказами. Реализованный штатный сценарий и проектные гарантии разделены в [проверках](docs/TESTING.md).

**Доходные слоты, пассивные выплаты, продажа системе, рынок, VIP и остальные крупные системы пока не реализованы.** Показанный «доход в слоте» — характеристика предмета, а не уже начисляемые рубли.

## Происхождение резервной копии

Исходники восстановлены из последних блоков кода переписки, с нормализованным форматированием. У помощника **нет прямого доступа к локальной Studio пользователя**. Это не побайтовый экспорт оригинального `.rbxl`. Изменения, сделанные в Studio вне переписки, могут отсутствовать.

Собранный `.rbxlx` содержит рабочее дерево скриптов, четыре RemoteEvent (два для слотов пока без обработчиков), простую площадку и точку появления. Геометрия исходной пользовательской сцены и её точные свойства не получены. Для полного оригинального снимка нужно добавить экспорт пользователя `NUMBER_RUSH.rbxl` или `.rbxlx`; инструкция в [STUDIO_SETUP.md](docs/STUDIO_SETUP.md).

Данные Roblox DataStore, игровые балансы пользователей и настройки доступа к API в Git не экспортированы. Имена хранилищ и форматы сохранены в [DATA_AND_PROTOCOL.md](docs/DATA_AND_PROTOCOL.md). Не переименовывать их для обычных изменений кода.

## Восстановить

См. [пошаговую инструкцию Studio](docs/STUDIO_SETUP.md). Можно открыть готовый `.rbxlx` либо перенести скрипты вручную. Rojo не обязателен.

```bash
python3 tools/build_place.py
python3 tools/verify_snapshot.py
```

Эти команды проверяют файловый снимок. Для реальной проверки Luau, API, конкурентной выдачи и сохранений необходим Roblox Studio.
