# Отключённые диагностические скрипты

Сохранены для контекста. Не входят в `default.project.json` или сгенерированный place.

- NumberRulesTest: 10 примеров классификации, 10 случайных генераций, 3 оценки стоимости.
- DataStoreCheck: увеличивает отдельный тестовый счётчик.
- BalanceSaveTest: **выставляет 90 000 ₽**, после проверки выключен пользователем. Не включать автоматически при восстановлении.

При ручном запуске помещать обычный Script в ServerScriptService, а после проверки отключать Enabled и сохранять редакторский проект.
